「數位工具如何真的幫上 NGO、小型組織，而非增加更多工作?」是我長期關心的題目，而 AI agent 趨於成熟的此刻，這題也有了完全不同的回答。

寫程式、資料與文本分析的成本大幅降低，改變的不只是「大家都寫得出會動的程式」，而是「身為小眾，也能專注於打磨產品，免於琢磨每一輪的實做成本」。過去一年，我從聊天機器人、網站、再寫到內部流程自動化，開發時間減少大半，而省下的時間，則拿去定義產品、描述使用者、驗證流程、理解團隊性格。程式節省了人們重複操作工具的力氣，而 agent 則讓人們更容易寫出合用的程式，程式終於開始成為像剪刀、膠水那樣的存在，大部分人都能拿它來創造自己的工具。

Agent 可以寫出程式，但要打磨出產品，還是得仰賴人類集體的經驗與信任。剪刀誰都拿得起來，難的是知道要剪什麼、剪壞了怎麼辦、剪完之後還能不能自己修——這是我最想貢獻的部分。

隨著山居生活即將展開，第四季開始，我終於又能來接案啦~我想理解更多 NGO、小組織的工作現場，也想促成更多點子落地。初期會以「8 小時 POC」為主：整整一天的工時，分散在一個月內進行。目標不是交付一套完整系統，而是把一個問題從「不知道能不能做」推到「知道能不能做、以及怎麼做」；過程盡量跟你們一起做，而不是我做完再交出去。每個案子我也會寫成公開紀錄，讓後面的人少走一段路，組織與細節可以匿名，事前談定就好。

聊聊不收費。如果大家有 agent 一小時解不了的問題、或不知道 agent 能否解得了的問題，歡迎來找我，一起找到落地的可能。
