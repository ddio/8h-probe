# 案例紀錄

每一次服務的公開紀錄，包含**成案**與**婉拒**兩類。

成案紀錄是任何顧問都做得出來的東西；婉拒紀錄的分布才是別人沒有的資料——收案準則會系統性地篩掉數位成熟度較低的組織，而那正是「小組織導入 AI 的難處」最集中的地方。

## 成案紀錄欄位

- 組織型態與規模
- 決策者結構（誰能拍板、需不需要理事會共識）
- 既有資料狀態（形式、數量、可用程度）
- 他們原本以為 AI 能做什麼
- 實際卡在哪一層（資料／流程／人的意願／授權／預算）
- 交付內容
- **交付後三個月，還有沒有人在用**（區分「示範成功」與「導入成功」的唯一證據）
- 自由文字段落，供日後深度分析

## 婉拒紀錄欄位

取成案欄位的前四項，加上：卡在三條收案準則的哪一條、當時的實際狀況。

## 匿名化規則

婉拒紀錄一律匿名化到組織型態層級（例如「中部、5 人以下、社福領域」），不出現組織名稱、聯絡人或其他可識別資訊。成案紀錄的組織名稱需經對方同意才公開。
